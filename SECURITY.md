# Security

Do not open a public issue for a suspected vulnerability or include credentials,
tokens, cookies, authorization codes, customer data, or private case data in a
report.

Report security issues privately through [GitHub private vulnerability
reporting](https://github.com/vamtaknebude/strata-plugin/security/advisories/new).
Include only the minimum reproduction details needed to understand the issue.

For installation defects that are not security-sensitive, use the public
[issue tracker](https://github.com/vamtaknebude/strata-plugin/issues).
