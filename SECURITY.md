# Security reporting

Do not open a public issue for a suspected vulnerability. Do not include
credentials, tokens, cookies, authorization codes, customer data, or private case
data in any public report.

After the repository becomes public, use GitHub's [private vulnerability reporting
form](https://github.com/vamtaknebude/strata-plugin/security/advisories/new). Before
that final publication step, contact a repository maintainer through an existing
private channel.

Include only the minimum reproduction details required to explain the issue.
Report installation defects that have no security impact in the repository [issue
tracker](https://github.com/vamtaknebude/strata-plugin/issues).
